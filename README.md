# MemoryLoop AI — Recruiter Demo

This is an interactive recruiter showcase that uses synthetic sample data only. Tasks, answers, feedback, and reminder interactions are simulated in your browser and remain browser-local; typed answers are not sent to a server or retained.

Open `index.html` in a modern browser, or serve this folder with a static web server. Explore the patient, caregiver, and clinician showcase pages, create a fictional task, and use **Reset demo** to restore the sample state.

This is an educational prototype, not a live clinical system, medical advice, diagnosis, treatment, or a clinically validated product. The full FastAPI application is not hosted by this static demo. It does not require that backend, SQLite, Whisper, or a private service.

The pages and assets use relative paths and support hosting beneath a GitHub Pages project subpath.
