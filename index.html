The problem space

A reminder can be easy to miss.
Practice makes the plan visible.

Remembering a future intention—an appointment, its time, and the items needed—can be demanding. MemoryLoop is a prototype for rehearsing that plan with familiar, simple prompts and supportive feedback.

  2. 2
    Practice recall

    The patient sees a short question and can type a response.

  3. 3
    Explain the result

    Simple deterministic rules show which configured concepts matched.

  4. 4
    Choose what to revisit

    An explainable demo rule prioritizes an incomplete category next.

Design principle

Supportive, not diagnostic.

Practice feedback in this prototype describes only the configured sample answer. It is not a cognitive assessment, diagnosis, prediction, or measure of treatment benefit.

The project does not claim a validated clinical outcome.

Two editions, clearly separated

The real local app has a backend.
This hosted demo does not.

The existing application is a local FastAPI prototype. This portfolio edition is a separate static experience designed to work on GitHub Pages without exposing or calling that application.
